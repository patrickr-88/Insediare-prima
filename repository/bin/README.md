# bin/

Place the built executables here:

- Windows: `USBInstaller.exe`, `repository-manager.exe`
- macOS:   `USBInstaller.app` (or the `USBInstaller` binary) and `repository-manager`

Both platforms' builds can live side by side on the same drive; the launchers
pick the right one. See `../../DEVELOPMENT.md` for how to produce them.
